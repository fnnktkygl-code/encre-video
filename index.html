Installer Encre Vidéo sur iOS

Pour ajouter Encre Vidéo sur l'écran d'accueil de votre iPhone / iPad :

  1. Appuyez sur le bouton Partager dans Safari.
  2. Sélectionnez Sur l'écran d'accueil.
  3. Appuyez sur Ajouter.

L'application s'exécutera ensuite comme une application native, 100% hors-ligne !
